## 2. 문제 정의

기존 오버투어리즘 해법은 대부분 "혼잡한 명소 → 한적한 대안 명소"로 유도하는 **공간 분산** 방식이다. 그러나 장소를 바꾸는 것은 여행자에게 계획 변경이라는 손실로 느껴져 실제 행동 변화로 이어지기 어렵다.

반면 **같은 장소를 다른 시간에 방문하는 것**은 손실이 거의 없다. 본 서비스는 "공간보다 시간을 먼저 재배치하는 것이 더 쉬운 해법"이라는 관점 전환을 핵심 가설로 삼는다.

---

## 3. 타겟 사용자

- 인파를 피해 여유롭게 여행하고 싶은 국내 자유여행객
- 여행 일정에 어느 정도 유연성이 있는 사용자 (당일/익일 등 날짜 조정 가능)

---

## 4. 서비스 범위

### 4.1 대상 지역

API에서 지원하는 **전국 모든 지역** 대응. 사용자가 임의 지역(시/도, 시/군/구)을 선택할 수 있으며, 특정 지역에 종속되지 않는 범용 구조로 설계한다.

> 주의: 전국 대응이므로 지역코드(areaCd/signguCd) 매핑 테이블 구축과 데이터 커버리지(모든 지역에 집중률/연관 데이터가 존재하지 않을 수 있음) 검증이 개발 초기 필수 작업이다.

### 4.2 In Scope (MVP에 포함)

1. 지역 선택 → 중심(인기) 관광지 목록 조회
2. 특정 관광지 선택 → 향후 30일 집중률(혼잡도 예측) 시각화
3. 동일 관광지 기준 연관(대안) 관광지 추천 목록
4. 자유 텍스트 입력 기반 조건 파싱 (예: "아이랑 갈만한 곳", "한적한 곳") → LLM이 카테고리/키워드로 변환해 추천 필터링에 반영
5. LLM 기반 자연어 추천 이유 + 코스 설명 생성
6. 시간 재배치에 따른 인센티브 UI 목업 (예: "이 시간대 방문 시 제휴 할인 예정" 등 비활성 상태 배지/카드로 표시, 실제 발급/결제 기능 없음)
7. 지도 시각화 (중심 관광지 + 연관 관광지 마커)

### 4.3 Out of Scope (MVP 제외, 향후 계획으로만 언급)

- 실제 쿠폰/할인 발급, 결제, 제휴사 연동
- 회원가입/로그인, 개인화 이력 저장
- 다국어 지원
- 실시간(분 단위) 혼잡도 — API 특성상 일 단위 집중률 예측으로 대체
- 네이티브 앱(iOS/Android) — 웹 반응형으로 대응

## 5. 기능 명세 (우선순위순)

### F1. 지역·관광지 탐색

- 시/도 → 시/군/구 순차 선택 UI
- 선택 지역의 중심 관광지 목록을 `hubRank` 순으로 표시 (카드형)
- API: `areaBasedList1` (중심 관광지 서비스)

### F2. 혼잡도 예측 시각화

- 관광지 선택 시 향후 30일 `cnctrRate` 라인차트 표시
- 집중률 최저 구간을 하이라이트하여 "추천 방문 시기"로 강조 표시
- API: `tatsCnctrRatedList`

### F3. 연관(대안) 관광지 추천

- 선택 관광지 기준 `rlteRank` 상위 N개 카드 표시
- 카테고리(자연/문화/맛집 등)별 필터 제공
- API: `areaBasedList1` (연관 관광지 서비스), 필요 시 `searchKeyword1`

### F4. 자유 텍스트 조건 파싱

- 사용자가 자연어로 조건 입력 (예: "아이랑 갈만한 한적한 곳")
- LLM이 이를 카테고리 코드/키워드로 변환 → F3 필터링 조건에 반영
- 파싱 실패/모호 시 카테고리 버튼 선택으로 폴백 제공

### F5. LLM 코스 설명 생성

- F1~F4 결과(JSON)를 LLM에 전달
- "OO는 지금 혼잡하니 [날짜]에 방문을 추천하며, 비슷한 성격의 △△도 함께 고려해보세요" 형태의 자연어 요약 생성
- 응답은 카드뉴스형 짧은 문단으로 구성 (과제 예시의 해시태그 컨셉과 일치)

### F6. 인센티브 목업

- 추천 시간대에 "제휴 할인/우선입장 예정" 등의 배지 UI만 표시
- 클릭 시 "추후 지자체·상점 제휴를 통해 실제 혜택으로 확장 예정" 안내 문구 노출
- 실제 백엔드 로직 없음 (정적 표시)

### F7. 지도 시각화

- 카카오맵 SDK 기반, 중심 관광지·연관 관광지 마커 표시
- 마커 클릭 시 F2, F5 요약 정보 팝업

## 8. 비기능 요구사항

- 데모 안정성: 공공데이터 API 장애 대비, 주요 조회 결과는 서버 캐시(정적 JSON 폴백) 적용
- 응답 형식: 모든 공공데이터 API 호출 시 `_type=json` 고정
- 인증키: 서버(API Route) 내에서만 사용, 클라이언트 노출 금지
- 반응형: 모바일/데스크톱 브라우저 대응

---

## 9. 성공 지표 (데모 기준)

- 임의 지역 선택 → 관광지 목록 → 혼잡도 차트 → 대안지 추천 → LLM 요약까지 전체 플로우가 끊김 없이 동작
- 자유 텍스트 입력이 실제로 추천 결과에 반영되는 것을 데모에서 시연 가능
- 최소 2개 이상 지역에서 정상 동작 확인 (전국 대응 주장의 근거)
